# ما و دنیای اطرافمون — نسخه نهایی تصاویر
وب‌سایت تک‌صفحه‌ای فارسی برای پروژه تولید محتوای مجازی، ویژه دانش‌آموزان نوجوان.

## اجرا
فایل `index.html` را با مرورگر باز کنید. برای ویرایش، کل پوشه را در VS Code باز کنید.

## فایل‌ها
- `index.html`: ساختار و متن هفت فصل
- `style.css`: هویت بصری، چیدمان Editorial و واکنش‌گرایی
- `script.js`: منوی موبایل، نوار پیشرفت، ورود تدریجی بخش‌ها و آزمون
- `assets/images/hero-community.webp`: تصویر سه‌بعدی تأییدشده برای بخش Hero.
- سایر جایگاه‌های تصویر فصل‌ها فعلاً خالی هستند تا پس از تأیید جداگانه تکمیل شوند.

## نکته
در این نسخه هیچ تصویر نهایی استفاده نشده و جایگاه هر تصویر با کادر موقت مشخص شده است. متن‌ها نسخه اولیه‌اند؛ آمارها و منابع دقیق باید قبل از تحویل نهایی با منابع معتبر بررسی و تکمیل شوند.


## قاب تصاویر هماهنگ با تم
پس‌زمینه قاب همه تصاویر در تم روشن تیره و در تم تیره روشن می‌شود و با دکمه تغییر تم هماهنگ است.
